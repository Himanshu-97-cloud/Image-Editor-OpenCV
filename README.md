# 🖼️ Image Editor using OpenCV

A simple Photoshop-inspired Image Editor built using **Python**, **OpenCV**, and **Streamlit**.

It allows users to perform common image processing operations such as resizing, cropping, rotating, flipping, brightness adjustment, contrast adjustment, grayscale conversion, HSV conversion, and saving edited images.

---

## 🚀 Features

- 📷 Load Image
- 📏 Resize Image
- ✂️ Crop Image
- 🔄 Rotate Image
- ↔️ Flip Image
- ☀️ Adjust Brightness
- 🎚️ Adjust Contrast
- ⚫ Convert to Grayscale
- 🌈 Convert to HSV
- 💾 Save Edited Image
- 🌐 Streamlit Web Interface

---

## 🛠️ Technologies Used

- Python
- OpenCV
- NumPy
- Streamlit

## ▶️ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/Image-Editor-OpenCV.git
```

Move into the folder

```bash
cd Image-Editor-OpenCV
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the Streamlit app

```bash
streamlit run app.py
```
